# Screenshots

The four images the root README's 2 × 2 table renders. Names are load-bearing —
the table references them by path.

Capture with **⌘⇧5 → Capture Selected Window**, which keeps the rounded corners
and the drop shadow. Take them on a Retina display and leave them at their native
size; GitHub scales them down to the table cell, and the extra pixels are what
keep the text crisp.

| File | What it should show |
| --- | --- |
| `explorer.png` | Details view in a folder with a mix of file types, sidebar open, preview panel showing a selected file. The default face of the app. |
| `split-layouts.png` | The 2 × 2 grid (View → Split Layout → 2 × 2 Grid) with four different folders, so the layout is obvious rather than four copies of one listing. |
| `photos.png` | Photos view (View → as Photos, or ⌘5) in a folder of images — stage image up top, filmstrip along the bottom. |
| `archives.png` | The compress dialog (select a few files → File → Compress…), with the format list and the password / splitting options visible. |

Two things worth doing before capturing:

- **Pick the theme deliberately.** The dark theme is the app's own look and is
  what the palette was designed around; light is newer. Whichever you choose,
  use the same one for all four — a table that mixes them reads as a bug.
- **Use a folder you would not mind the internet reading.** These end up in a
  public README, filenames and all.
