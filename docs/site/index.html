FileBase

A fast, native-feeling file explorer for macOS. Tabs, split panes, archives you can walk into, checksums, and a reader for files bigger than your memory.

Download for macOS Read the guide

Free and open source · Apple silicon and Intel · macOS 10.13 or later

Everything a file manager should do, and a few things Finder doesn't

Tabs and nine split layouts

Open tabs like a browser, then split any tab into two, three or four panes. Each pane has its own folder, history and selection, so you can drag files straight from one to another.

Tabs and split panes →

Five ways to look at a folder

Details, three sizes of icons, and a Photos view with a big stage image and a filmstrip. FileBase remembers the view for each folder, so Pictures can stay on photos while Documents stays on details.

Views →

Archives that open like folders

Double-click a zip, 7z, rar or tarball and browse it like any other folder. Compress to zip or tar, with optional splitting and an AES-256 password.

Archives →

Checksums you can actually check

Hash any file with SHA-256, SHA-512, MD5 and more. Paste the checksum from a download page and the matching file lights up. If you picked the wrong algorithm, FileBase tells you which one the checksum looks like.

Checksums →

Read a 100 GB log file

The text reader shows one window of a file at a time, so a huge file costs the same as a small one. Jump anywhere with the slider or by typing a byte offset.

Text reader →
