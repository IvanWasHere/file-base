## Tags

![The Tags window for a document with the seven Finder colours]({{ '/assets/img/guide/tags.png' | relative_url }})

Select one or more files and press <kbd>⌥⌘T</kbd>, or right-click and choose **Tags…**.

- Tick a tag to add it, and untick it to remove it. The change applies to **everything selected**.
- Create a **new tag** at the bottom: type a name, pick a colour and click **Add**.

These are real macOS tags, the same ones Finder uses. Tag something in FileBase and it shows up tagged in Finder, Spotlight and the Finder sidebar, and the other way round.

## Open With

![The Open With picker listing suggested and all applications]({{ '/assets/img/guide/open-with.png' | relative_url }})

Double-clicking opens a file in its default app. To use a different one:

- **Right-click → Open With** shows a list of apps right in the menu.
- **File → Open With…** opens a searchable picker. **Suggested** apps are the ones macOS says can open this type of file, and **All Applications** lists everything else.

Your choice applies **this once**. It doesn't change the default app for that file type.
