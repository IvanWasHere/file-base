## Tabs

| Action | How |
| --- | --- |
| New tab | <kbd>⌘T</kbd>, or **+** at the right of the tab bar |
| Close tab | <kbd>⌘W</kbd> |
| Open a folder in a new tab | Right-click it → **Open in New Tab** |
| Switch tabs | Click the tab |

Each tab keeps its own layout and folders. Close FileBase and reopen it, and your tabs are all still there.

## Split layouts

![Four panes in a 2 × 2 grid showing Documents, Wallpapers, Downloads and Projects]({{ '/assets/img/guide/split-grid.png' | relative_url }})

Any tab can be split into several **panes**. Each pane is a full browser with its own folder, history, view and selection. Choose a layout from the **layout picker** in the toolbar or from **View → Split Layout**:

![The View menu with the Split Layout submenu open]({{ '/assets/img/guide/menu-view.png' | relative_url }})

| Layout | Panes |
| --- | --- |
| Single Pane | 1 |
| 2 Columns / 2 Rows | 2, side by side or stacked |
| 3 Columns | 3, side by side |
| Split Top / Bottom / Left / Right | 3: one large pane and two smaller ones |
| 2 × 2 Grid | 4 |

### Working with panes

- **Click inside a pane** to make it active. The toolbar, menus and shortcuts then act on that pane. Panes are labelled **A**, **B**, **C** and **D**, and the active one's letter is highlighted.
- **Drag the dividers** to resize panes. FileBase remembers the sizes.
- **Drag files from one pane to another** to move or copy them. See [File operations](../files/#drag-and-drop).

A common setup: **2 Columns**, with the folder you're sorting on the left and where things should go on the right.
