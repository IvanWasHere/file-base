## Opening folders and files

- **Double-click** a folder to go into it, or a file to open it in its default app.
- Select something and press <kbd>⌘O</kbd> or <kbd>⌘↓</kbd> to do the same from the keyboard.
- Right-click a folder and choose **Open in New Tab** to keep your place here and open it next door.

<kbd>Return</kbd> **renames** the selected item, like in Finder. It doesn't open it.

## Going back

| Action | Shortcut |
| --- | --- |
| Back | <kbd>⌘[</kbd> or <kbd>⌘←</kbd> |
| Forward | <kbd>⌘]</kbd> or <kbd>⌘→</kbd> |
| Enclosing folder | <kbd>⌘↑</kbd> |

Each pane keeps its own history, so Back in one pane never moves another.

## Jumping to common places

The **Go** menu and its shortcuts take you straight to the usual folders:

| Place | Shortcut |
| --- | --- |
| Home | <kbd>⇧⌘H</kbd> |
| Documents | <kbd>⇧⌘O</kbd> |
| Downloads | <kbd>⌥⌘L</kbd> |
| Applications | <kbd>⇧⌘A</kbd> |

You can also click any part of the **path** in the toolbar to jump to that folder, or use the sidebar and the icon rail.

## Favorites and Recent

Star a folder with the ☆ button in the toolbar, or right-click it and choose **Add to Favorites**. It then appears under **Favorites** in the sidebar. Click the star again to remove it.

The **Recent** section fills itself with the folders you've been visiting.

## Selecting with the keyboard

With the listing focused:

- **Arrow keys** move the selection, and <kbd>Home</kbd> / <kbd>End</kbd> jump to the first and last item.
- **Start typing a name** to jump to it. Type "meet" and the selection lands on *Meeting Notes.docx*.
- <kbd>⌘A</kbd> selects everything. Deselect All is in the Edit menu.

With the mouse:

- <kbd>⌘</kbd>-click adds or removes single items.
- <kbd>⇧</kbd>-click selects a range.
- Drag across an empty area to draw a selection box.

## Hidden files

Press <kbd>⇧⌘.</kbd> (or **View → Show Hidden Files**) to show dotfiles and other hidden items. Press it again to hide them.

## Folders stay up to date

You never need to refresh. When something changes in a folder you have open, whether from another app, the Terminal or a download finishing, the listing updates on its own. <kbd>⌘R</kbd> is there if you want it anyway.
