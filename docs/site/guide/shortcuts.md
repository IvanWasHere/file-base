On an external PC keyboard, <kbd>Ctrl</kbd> works in place of <kbd>⌘</kbd>.

## File

| Command | Shortcut |
| --- | --- |
| Open | <kbd>⌘O</kbd> or <kbd>⌘↓</kbd> |
| New File | <kbd>⌘N</kbd> |
| New Folder | <kbd>⇧⌘N</kbd> |
| New File from Template… | <kbd>⌥⌘N</kbd> |
| New Tab | <kbd>⌘T</kbd> |
| Close Tab | <kbd>⌘W</kbd> |
| Rename | <kbd>Return</kbd> |
| Duplicate | <kbd>⌘D</kbd> |
| Move to Trash | <kbd>⌫</kbd> or <kbd>⌦</kbd> |
| Delete Immediately… | <kbd>⇧⌫</kbd> or <kbd>⇧⌦</kbd> |
| Compress… | <kbd>⌥⌘K</kbd> |
| Calculate Hashes… | <kbd>⌥⌘H</kbd> |
| Reveal in Finder | <kbd>⇧⌘R</kbd> |
| Copy Path | <kbd>⌥⌘C</kbd> |
| Tags… | <kbd>⌥⌘T</kbd> |
| Settings… | <kbd>⌘,</kbd> |

## In the listing

| Action | Keys |
| --- | --- |
| Move the selection | <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> |
| First / last item | <kbd>Home</kbd> / <kbd>End</kbd> |
| Jump to an item by name | Start typing its name |
| Add to the selection | <kbd>⌘</kbd>-click |
| Select a range | <kbd>⇧</kbd>-click |
| Clear the selection | <kbd>Esc</kbd> |
| Previous / next photo (Photos view) | <kbd>←</kbd> / <kbd>→</kbd> |

## While typing a name

When you're renaming or typing in a search box, keys go to the text. <kbd>⌘C</kbd> copies text, not files, and <kbd>⌫</kbd> deletes characters, not files. <kbd>Return</kbd> saves and <kbd>Esc</kbd> cancels.
